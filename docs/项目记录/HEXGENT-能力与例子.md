# MindWeave Harness 在这个工作台里能做什么（附具体例子）

> 一句话：MindWeave Harness 是**Agent 的运行时**——它不管界面、不管知识库，它负责"让模型安全地调用工具、把过程记下来、出错能恢复"。
> 这份文档只讲**在你现在这个工作台里**能做什么、怎么试、哪些还没接上。

---

## 0. 先分清三层

```text
界面（MindWeave 前端）      → 你看到的对话、知识库、笔记
运行时（MindWeave Harness）           → 工具调用、权限、恢复、上下文、预算
能力（业务/文件/代码）       → 检索、读写文件、执行 Python、笔记、图谱
```

MindWeave Harness 不是模型，也不是"更聪明的回答"。它的价值在：**模型想动手时，谁批准、怎么执行、失败怎么办、事后怎么查**。

---

## 1. 六个能力 + 在本项目里的例子

### ① 工具调用：让模型"动手"，而不是只说话

**能做什么**：把文件、代码、检索、笔记这些能力注册成工具，模型自己决定调用。

**已接进工作台**：

| 工具 | 类型 | 例子（直接输入） |
|---|---|---|
| `write_file` | 写（需审批） | 「在工作区创建 `notes/ideas.md`，内容是：把缓存击穿整理成清单」 |
| `read_file` | 读 | 「读取工作区 `notes/hello.md` 的内容」 |
| `list_files` | 读 | 「列出我工作区里的文件」 |
| `run_python` | 写（需审批） | 「用 Python 算 12、18、27 的标准差并运行」 |
| `search_rag` | 读 | 「我的笔记里怎么写缓存击穿？」 |
| `create_note` / `mark_reviewed` / `remember` | 写（需审批） | 「把这段整理成一篇笔记」 |

**实际效果**（已验证）：

```text
你：创建 notes/hello.md，内容 Hello MindWeave Harness
Agent：申请 write_file → 弹审批 → 你点同意
磁盘：workspace/294cb.../notes/hello.md
内容：Hello MindWeave Harness，这是工作台创建的文件。
```

---

### ② 权限与审批：写操作必须过你这一关

**能做什么**：

- 读操作直接执行；写操作（建文件、跑代码、写笔记、记记忆）**弹审批**；
- 没有确认界面时 **fail-closed**（不执行），而不是"默认同意"；
- **本会话都允许**：同一类操作 1 小时内不再重复问；
- 路径限制：`write_file` 只能在 `workspace/<你的用户ID>/` 内，`../` 会被拒绝。

**例子**：

```text
你：创建 notes/a.md
Agent：[审批卡] 写入文件：notes/a.md（12 字符）
      [同意] [本会话都允许] [拒绝]

你：再创建 notes/b.md
Agent：write_file 已按本次会话的授权直接执行   ← 不再弹卡
```

**已验证**：重复点审批第二次返回"没有可恢复的审批"，文件数量 1→1，不会重复写。

---

### ③ 会话持久化与恢复：崩了能接着跑

**MindWeave Harness 的机制**：

```text
transcript.jsonl（唯一事实）
  → checkpoint（加速器，校验和+序号）
  → 校验失败回退全量重放
  → 未闭合工具三态：not_started / safe_to_retry / verify_before_retry
```

**在工作台里**：MindWeave 后端有会话与审批状态机，但**还没有三态判定**。所以"崩在工具中间"目前只能靠审批状态机兜底（`executing` → 要求人工核对），不能自动判定。

**能演示的**：审批执行到一半断线，重新打开会话仍能看到待处理/已处理状态（不会重复写）。

**还没接的**：MindWeave Harness 那套 `kill -9 后从 transcript 恢复并继续`。

---

### ④ 上下文管理：长对话不爆、不丢关键信息

**能做什么**：

- 预算派生：128K 窗口 → 64K 主动压缩 / 120K 阻塞线；
- 只在**完整轮次边界**切，不把工具调用和结果拆开；
- 关键事实带来源哈希，压缩后可核对；
- **剪枝优先**：可再生的工具结果换成指针（实测：调用 12→4 次，压缩阶段 token −76%）。

**在工作台里**：MindWeave 有自己的"归档 + 六段式摘要 + 按页读回"。两套没有合并——MindWeave Harness 的剪枝/原子提交还没接进 MindWeave 的循环。

---

### ⑤ 预算与收尾：不让 Agent 跑飞

**MindWeave Harness 有**：轮次、工具次数、token、单轮输出、墙钟五类预算；命中后进入 finalizing（禁工具），明确终态 `limit_reached`，且要求不能把未完成 Plan 标成完成。

**在工作台里**：MindWeave 有轮次上限、重复调用检测、180s 请求超时；**五类预算与 finalizing 还没接**。

---

### ⑥ 并行工具与结果配对：多源检索更快

**MindWeave Harness 有**：只读工具按并发安全分组并行、写操作形成屏障、结果按模型原序回填、每个 `call_id` 恰好一条回执。

**在工作台里**：MindWeave 的循环**每轮只允许一个工具调用**，所以并行没生效。

**可以做但还没做**：把 MindWeave Harness 的分组/屏障/配对搬进 MindWeave 循环，多检索并行（预计 2–3x）。

## 2. 现在就能演示的 5 个例子

### 例 1：建文件并回读

```text
你：在工作区创建 notes/demo.md，内容是「MindWeave Harness 能创建文件」
→ 审批 → 同意
你：读取 notes/demo.md
→ Agent 返回文件内容
```

### 例 2：写代码算数

```text
你：必须调用 run_python，计算 12、18、27 的标准差
→ 审批 → 同意
→ stdout: population std 6.164…，退出码 0
```

### 例 3：本会话免重复审批

```text
你：创建 notes/a.md → 选「本会话都允许」
你：创建 notes/b.md → 不再弹审批，直接执行
```

### 例 4：检索并引用

```text
你：缓存击穿怎么处理？
→ 回答带 [1][2]，可点开来源卡，跳到知识库并高亮切片
```

### 例 5：重复审批不重复执行

```text
第一次批准 → 文件生成
再次点批准 → "没有可恢复的审批"，文件数不变
```

## 4. 怎么演示（面试/自测）

```text
1. 打开 http://127.0.0.1:3100，登录 demo/demo1234
2. 输入：在工作区创建 notes/demo.md，内容「你好」
3. 观察右侧轨迹：agentic_plan → 调用 write_file → 等待审批

5. 再输入：读取 notes/demo.md → 内容回显
```

每一步都能在右侧「执行轨迹」里看到：**规划、工具调用、审批、执行、结果**。

## 5. 一句话总结

> MindWeave Harness 干的是"**模型想动手时的安全通道**"：工具怎么注册、写操作谁批准、执行失败怎么判定、上下文怎么不爆、过程怎么留痕。
> 在这个工作台里，**文件、代码、审批、引用**已经能用；**恢复、并行、预算、计划**还留在 MindWeave Harness 侧，等下一步接进来。
