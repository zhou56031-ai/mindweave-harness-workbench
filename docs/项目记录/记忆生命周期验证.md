# 记忆生命周期验证（真实模型 + 真实 MySQL）

日期：2026-11-08 ｜ 后端：MindWeave（FastAPI + MySQL）｜ 模型：deepseek-flash

## 步骤与结果

| 步骤 | 操作 | 结果 |
|---|---|---|
| 1 | 写入记忆：`用户的名字是 ZQX-742，喜欢用 Python` | 成功，id `1a2447f4…` |
| 2 | 新会话提问“我的名字是什么？” | 正确召回 `ZQX-742` ✅ |
| 3 | 删除该记忆 | `200 已删除` |
| 4 | 撤销后连续 8 次新会话提问 | **0/8** 注入失效记忆 ✅ |

## 结论

- 记忆为 MySQL 结构化存储，请求时按权威状态重建注入，删除后不会复活；
- 验证覆盖“写入 → 召回 → 撤销 → 不再注入”完整生命周期；
- 记忆按用户维度隔离。

## 复现要点

- 使用独特标记 `ZQX-742`，避免模型凭空猜测干扰判断；
- 每次请求都新建会话，确保验证的是跨 Session 注入；
- 客户端需 `trust_env=False`，避免本机代理干扰。
